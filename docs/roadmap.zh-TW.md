# Roadmap

[English](roadmap.md) | [繁體中文](roadmap.zh-TW.md)

## v0.1 — foundation

- Codex plugin manifest 與 marketplace metadata。
- GitLab.com Hosted MCP integration。
- 一般 GitLab routing skill。
- Setup/authentication workflow。
- Commit/push/open-MR workflow。
- MR feedback workflow。
- CI failure workflow。
- 英文 + 繁體中文文件。
- CI validation。

## v0.2 — compatibility

- 建立 GitLab.com 與代表性 Self-Managed 版本 test matrix。
- 更完整的 capability probing 與 fallback 規則。
- 擴充 issue/MR labels、reviewers、milestones、work items 指南。
- 加入 release/tag workflow。

## v0.3 — safety and UX

- 加入 plugin evaluation / benchmark fixtures。
- 多 remote repo 寫入前提供更強的 target confirmation helper。
- 增加 multi-account / multi-host `glab` 範例。
- 增加更多 CI/pipeline 修復場景。

## Future — public distribution

- 評估 Plugin Directory 使用的 hosted app/connector layer。
- 加入適合非本機 ChatGPT/Codex surface 的 OAuth/app configuration。
- 準備 assets、screenshots、privacy/terms metadata 與 submission materials。

即使未來加入 hosted connector，本機開源 plugin 仍應可以獨立使用。
